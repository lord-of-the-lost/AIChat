# Swift Playground Docker

Этот контейнер используется для безопасного выполнения Swift кода в изолированной среде.

## Использование

### Автоматическое (через приложение)
Приложение автоматически создает временные файлы и запускает их в этом контейнере.

### Ручное тестирование

1. Создайте файл `main.swift`:
```swift
print("Hello, Swift Playground!")
let a = 5
let b = 3
print("Результат сложения: \(a + b)")
```

2. Запустите контейнер:
```bash
docker-compose up --build
```

## Безопасность

- Контейнер изолирован от сети
- Файловая система ограничена рабочей директорией
- Автоматическое удаление после выполнения

## Возможности

- Компиляция и выполнение Swift кода
- Поддержка стандартной библиотеки Swift
- Быстрое время запуска
- Изолированная среда выполнения
