# 🤖 AI Chat с Swift Playground

Десктопное приложение для macOS, которое объединяет AI чат с возможностью выполнения и тестирования Swift кода.

## ✨ Основные возможности

### 🗣️ AI Чат
- Интеграция с OpenAI API через прокси
- Поддержка русского языка
- Интеграция с GitHub через MCP (Model Context Protocol)
- Сохранение API ключей и токенов

### 🚀 Swift Code Execution
- **Docker контейнеры** - безопасное выполнение в изолированной среде
- **Native Swift** - быстрое выполнение как fallback
- Автоматическое определение метода выполнения
- Подробные результаты выполнения

### 🧪 **НОВОЕ: Автоматическое тестирование Swift кода**
- **Генерация unit тестов** - AI создает comprehensive тесты для вашего кода
- **Выполнение тестов** - тесты запускаются в Docker контейнерах
- **Автоматическое исправление** - AI исправляет код на основе результатов тестов
- **Итеративное тестирование** - цикл повторяется до успешного прохождения всех тестов
- **Подробная отчетность** - детальная информация о каждой итерации

### 🔍 **НОВОЕ: Автоматическое ревью GitHub Pull Requests**
- **AI ревью кода** - автоматический анализ PR с помощью AI
- **Пайплайн ревью** - последовательное ревью всех файлов с накоплением контекста
- **Создание issues** - автоматическое создание GitHub issues на основе найденных проблем
- **Комментарии к PR** - добавление детальных комментариев с результатами ревью
- **Группировка проблем** - умная группировка проблем по приоритету и типу
- **Поддержка всех языков** - работает с любыми языками программирования
- **Обработка больших PR** - эффективная работа с PR любого размера

## 🏗️ Архитектура

### Основные компоненты
- **SwiftUI** - современный UI для macOS
- **Docker** - изолированное выполнение кода
- **MCP (Model Context Protocol)** - интеграция с внешними сервисами
- **AI Integration** - OpenAI API для генерации тестов и исправления кода

### Компоненты тестирования
1. **SwiftTestGenerator** - генерирует unit тесты с помощью AI
2. **SwiftTestRunner** - выполняет тесты в Docker контейнерах
3. **SwiftCodeFixer** - автоматически исправляет код на основе результатов тестов
4. **SwiftTestOrchestrator** - управляет полным циклом тестирования

### Компоненты ревью PR
1. **GitHubPRService** - работа с GitHub API для PR и issues
2. **CodeReviewService** - AI ревью кода с пайплайном батчей
3. **PullRequest** - модели данных для PR и ревью
4. **ReviewResultView** - UI для отображения результатов ревью
5. **BatchReviewResult** - результаты ревью отдельных батчей

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Установка Python зависимостей для MCP Docker сервиса
cd mcp-docker
python -m venv venv
source venv/bin/activate  # На macOS/Linux
pip install -r requirements.txt
```

### 2. Запуск MCP Docker сервиса

```bash
cd mcp-docker
source venv/bin/activate
python app.py
```

### 3. Запуск приложения

Откройте `AIChat.xcodeproj` в Xcode и запустите схему `AIChatMac`.

## 📖 Использование

### Обычное выполнение Swift кода

Отправьте Swift код в чат:

```
print("Hello, World!")
let x = 2 + 2
print("2 + 2 = \(x)")
```

### **Автоматическое тестирование Swift кода**

Отправьте код с ключевыми словами для тестирования:

```
Проверь этот код:
class Calculator {
    func add(_ a: Int, _ b: Int) -> Int {
        return a + b
    }
}
```

**Ключевые слова для активации тестирования:**
- `тест`
- `test` 
- `проверь`
- `проверить`
- `unit`
- `юнит`

### **Автоматическое ревью GitHub Pull Requests**

Отправьте ссылку на GitHub PR для автоматического ревью:

```
https://github.com/username/repository/pull/123
```

**Что происходит автоматически:**
1. **Пайплайн ревью** - последовательный анализ всех файлов по батчам
2. **Накопление контекста** - передача важной информации между батчами
3. **Анализ кода** - AI анализирует изменения в каждом батче
4. **Создание issues** - автоматическое создание GitHub issues для найденных проблем
5. **Комментарий к PR** - добавление детального комментария с результатами ревью
6. **Группировка проблем** - умная группировка по приоритету (критические, высокие, средние, низкие)

### Примеры использования тестирования

#### Пример 1: Простой класс
```
Создай тесты для этого класса:
class StringProcessor {
    func reverse(_ text: String) -> String {
        return String(text.reversed())
    }
}
```

#### Пример 2: Класс с ошибками (будет автоматически исправлен)
```
Проверь этот код:
class BuggyCalculator {
    func add(_ a: Int, _ b: Int) -> Int {
        return a - b  // Ошибка
    }
}
```
