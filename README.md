# AIChat - AI Agent для исправления проблем в GitHub PR

## Описание

AIChat - это macOS приложение, которое работает как AI агент для автоматического исправления проблем в GitHub Pull Requests. Приложение анализирует описание проблемы, генерирует исправление и создает новый PR с решением.

## Основные возможности

### 🔧 Исправление проблем
- **Инфраструктурные проблемы**: GitHub Actions, CI/CD, автоматизация сборки
- **Проблемы безопасности**: безопасное хранение токенов, ключей, паролей
- **Проблемы производительности**: оптимизация кода, улучшение скорости
- **Архитектурные проблемы**: улучшение структуры кода, паттерны
- **Проблемы стиля**: форматирование, конвенции кода

### 🚀 Автоматизация
- Автоматический анализ описания проблемы
- Генерация кода исправления с помощью AI
- Создание новой ветки и коммита
- Создание Pull Request с исправлением
- Интеграция с GitHub API
- **Локальное создание файлов**: Создание файлов напрямую в указанной директории

## Как использовать

### 1. Запуск приложения
```bash
# Откройте проект в Xcode
open AIChat.xcodeproj

# Или скомпилируйте из командной строки
xcodebuild -project AIChat.xcodeproj -scheme AIChatMac -configuration Debug build
```

### 2. Настройка GitHub токена
1. Создайте Personal Access Token в GitHub
2. Добавьте токен в настройки приложения
3. Убедитесь, что токен имеет права на создание PR и коммитов

### 3. Использование AI агента

#### Для GitHub PR (создание Pull Request с исправлением)
Отправьте сообщение в формате:
```
https://github.com/owner/repo/pull/123 Описание проблемы
```

Примеры:
```
https://github.com/lord-of-the-lost/AIChat/pull/1 Надо поготовить гитхаб экшенс для того чтобы убедиться в том что код билдится
```

```
https://github.com/lord-of-the-lost/AIChat/pull/1 Надо добавить безопасное храение токенов
```

#### Для локальных директорий (создание файлов локально)
Отправьте сообщение в формате:
```
/путь/к/локальной/директории Описание проблемы
```

**AI автоматически:**
- Анализирует описание проблемы
- Определяет тип решения (GitHub Actions, Security, Performance, Testing, Generic)
- Генерирует уникальный контент с помощью AI
- Создает соответствующие файлы и директории

**Примеры:**
```
/Users/n.s.ignatov/Downloads/MainFolder/Development/AIChat Надо поготовить гитхаб экшенс для того чтобы убедиться в том что код билдится
```

```
/Users/n.s.ignatov/Downloads/MainFolder/Development/AIChat Надо добавить безопасное храение токенов
```

```
/Users/n.s.ignatov/Downloads/MainFolder/Development/AIChat Надо улучшить производительность приложения
```

```
/Users/n.s.ignatov/Downloads/MainFolder/Development/AIChat Надо добавить тестирование кода
```

## Архитектура приложения

### Основные компоненты

#### 1. MacChatViewModel
- Управляет UI и взаимодействием с пользователем
- Обрабатывает входящие сообщения
- Координирует работу сервисов

#### 2. ChatService
- Основной сервис для обработки сообщений
- Определяет тип запроса (PR ревью vs исправление проблемы)
- Вызывает соответствующие сервисы

#### 3. CodeReviewService
- Анализирует описание проблемы
- Генерирует исправления с помощью AI
- Координирует создание PR

#### 4. GitHubPRService
- Взаимодействие с GitHub API
- Создание веток, коммитов, PR
- Обработка ошибок API

#### 5. LocalFileService
- AI-генерация уникального контента для файлов
- Создание файлов в локальных директориях
- Автоматическое создание директорий
- Анализ типа проблемы и выбор подходящего решения

### Типы проблем

#### Infrastructure
- GitHub Actions workflows
- CI/CD конфигурация
- Автоматизация сборки

#### Security
- Безопасное хранение токенов
- Шифрование данных
- Управление ключами

#### Performance
- Оптимизация кода
- Улучшение алгоритмов
- Кэширование

#### Architecture
- Рефакторинг структуры
- Паттерны проектирования
- Модульность

#### Style
- Форматирование кода
- Конвенции именования
- Документация

## Процесс работы

1. **Парсинг URL**: Извлечение owner/repo/PR number
2. **Получение данных PR**: Загрузка информации о PR через GitHub API
3. **Анализ проблемы**: Определение типа проблемы по ключевым словам
4. **Генерация исправления**: Создание кода с помощью AI
5. **Создание ветки**: Новая ветка для исправления
6. **Создание коммита**: Добавление исправления в репозиторий
7. **Создание PR**: Pull Request с описанием изменений

## Обработка ошибок

### GitHub API ошибки
- 422: Resource already exists (ветка/PR уже существует)
- 401: Unauthorized (неверный токен)
- 404: Not found (репозиторий/PR не найден)

### Ошибки компиляции
- Проверка синтаксиса Swift кода
- Валидация структур данных
- Обработка опциональных полей

## Разработка

### Структура проекта

### Добавление новых типов проблем
1. Добавьте ключевые слова в `analyzeIssueDescription`
2. Создайте функцию генерации исправления
3. Добавьте case в `generateFixForSpecificIssue`
