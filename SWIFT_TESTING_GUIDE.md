# 🧪 Руководство по автоматическому тестированию Swift кода

## Обзор

Новая функциональность позволяет автоматически создавать и выполнять unit тесты для Swift кода прямо в чате. Система работает по следующему алгоритму:

1. **Генерация тестов** - AI создает comprehensive unit тесты для предоставленного кода
2. **Выполнение тестов** - Тесты запускаются в изолированной среде
3. **Анализ результатов** - Система анализирует успешные и неудачные тесты
4. **Автоматическое исправление** - AI исправляет код на основе результатов тестов
5. **Повторное тестирование** - Цикл повторяется до успешного прохождения всех тестов

## Как использовать

### 1. Отправка кода для тестирования

Отправьте Swift код в чат с ключевыми словами, указывающими на необходимость тестирования:

```
Проверь этот код:
class Calculator {
    func add(_ a: Int, _ b: Int) -> Int {
        return a + b
    }
}
```

**Ключевые слова для активации тестирования:**
- `тест`
- `test` 
- `проверь`
- `проверить`
- `unit`
- `юнит`

### 2. Примеры использования

#### Пример 1: Простой класс
```
Создай тесты для этого класса:
class StringProcessor {
    func reverse(_ text: String) -> String {
        return String(text.reversed())
    }
}
```

#### Пример 2: Класс с ошибками (будет автоматически исправлен)
```
Проверь этот код:
class BuggyCalculator {
    func add(_ a: Int, _ b: Int) -> Int {
        return a - b  // Ошибка
    }
}
```

#### Пример 3: Несколько классов
```
Создай unit тесты для этих классов:
class Calculator {
    func add(_ a: Int, _ b: Int) -> Int { return a + b }
    func multiply(_ a: Int, _ b: Int) -> Int { return a * b }
}

class StringUtils {
    func isPalindrome(_ text: String) -> Bool {
        let cleaned = text.lowercased().filter { $0.isLetter }
        return cleaned == String(cleaned.reversed())
    }
}
```

## Архитектура системы

### Компоненты

1. **SwiftTestGenerator** - Генерирует unit тесты с помощью AI
2. **SwiftTestRunner** - Выполняет тесты в изолированной среде
3. **SwiftCodeFixer** - Автоматически исправляет код на основе результатов тестов
4. **SwiftTestOrchestrator** - Управляет полным циклом тестирования

### Ограничения

- Максимум 5 итераций исправления
- Поддерживаются только базовые Swift конструкции
- Тесты выполняются в упрощенной среде (без XCTest framework)

## Технические детали

### Среда выполнения
- Docker контейнеры (приоритет)
- Native Swift (fallback)
- Изолированная среда для безопасности

### Генерация тестов
- Использует AI для создания comprehensive тестов
- Покрывает все публичные методы
- Включает edge cases и граничные условия

### Автоматическое исправление
- Анализирует ошибки тестов
- Генерирует исправленный код
- Сохраняет логику и структуру

## Советы по использованию

1. **Четко описывайте функциональность** - AI лучше генерирует тесты для хорошо описанного кода
2. **Используйте простые конструкции** - Сложные Swift фичи могут не поддерживаться
3. **Проверяйте результаты** - Всегда просматривайте сгенерированные тесты
4. **Итеративный подход** - Если тесты не прошли, попробуйте упростить код

## Ограничения и известные проблемы

- Не поддерживаются сложные Swift фичи (generics, protocols, etc.)
- Ограниченная поддержка XCTest framework
- Максимум 5 попыток автоматического исправления
- Требуется подключение к интернету для AI функций
